В сентябре Яндекс выложил Alice AI Foundation LLM — модель на 80 млрд параметров, обученную с нуля. Лицензия Apache 2.0 позволяет использовать её коммерчески.

На первый взгляд, Яндекс сделал свою модель — и это хорошая новость. Но важнее архитектура MoE с 3 млрд активных параметров. Модель весит как большая, но в момент работы использует только 3 млрд. Это делает её дешёвой в инференсе: не по цене токена у провайдера, а по вычислительным мощностям, необходимым для запуска.

## Что это значит

- Модель можно запустить на железе, которое есть у среднего российского корпората.
- Для российского рынка это критично: доступ к большим вычислительным ресурсам ограничен, и чем эффективнее модель, тем шире круг компаний, которые могут её использовать.
- По качеству на русскоязычных фактах модель обгоняет более крупные открытые аналоги, включая DeepSeek с 284 млрд параметров.

Для российского рынка, где GPU — дефицит, это может оказаться правильной ставкой.
