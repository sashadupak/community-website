Анализ исторического массива спутниковых снимков позволяет сократить дискретность данных до ежедневной поставки для повышения безопасности навигации по Северному морскому пути.

## Суть кейса:
Спутники снимают ледовую обстановку на Северном морском пути, но из-за особенностей орбит на картах классификации льда остаются пробелы — до 30% акватории. Задача: нейросеть, которая заполняет пропуски, анализируя исторический массив спутниковых снимков.

## Зачем это нужно:
Сейчас данные о ледовых условиях на ряде участков СМП приходят с разрывами в несколько дней. Рабочее решение доведёт поставку данных до ежедневной — это критично для нефтегазовых компаний, морских перевозчиков, промысловых и страховых компаний.

ООО «ВИЗАРД» — ИТ-компания из реестра Минцифры, разработчик Платформы VIZARD для мониторинга арктической обстановки. Победитель конкурса инновационных проектов для Арктики «АРКТЕК», лауреат Российско-Китайского конкурса промышленных инноваций.
