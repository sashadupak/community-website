# AI Business SPb — исходный код сайта

Статический сайт без внешних библиотек. Чтобы обновить материалы, измените Markdown-файлы в `content/` и запустите `python3 build.py` из корня проекта.

## Структура

- `index.html` — страницы сообщества, материалов и программ, блок премии и оверлей статьи.
- `css/styles.css` — дизайн и адаптивные правила.
- `js/app.js` — навигация, лента и отображение статей.
- `js/layout.js` — раскладка ленты по сетке из 12 колонок.
- `js/posts.js` и `js/cases.js` — генерируемые индексы; вручную их не редактировать.
- `content/posts/*.md` — по одному файлу на материал.
- `content/cases/*.md` — кейсы компаний.
- `assets/logos/` — логотипы компаний в PNG.
- `assets/hackathon/` — фото хакатона и страницы программы.
- `assets/hackathon/cases/` — фото кейсов.
- `assets/posts/<slug>/` — обложка и изображения конкретной статьи.
- `assets/award.png` — изображение премии; оно используется только в блоке о премии на странице программ.
- `build.py` — сборщик индексов; `bundle.py` — создание единого HTML-файла.

## Добавить материал

1. Скопируйте файл из `content/posts/` и задайте ему имя-slug латиницей с дефисами, например `my-project.md`.
2. Заполните поля между строками `---`: `title`, `date` (ГГГГ-ММ-ДД), `size` (`мини`, `средняя`, `большая` или внутреннее значение `статья`), `accent` (`да`/`нет`), при необходимости `kind: event`, `featured: true`, `draft: true`, `format`, `topic`, `note`, `author` и `cover`. Значение `статья` задаёт большую карточку, но не выводится как тег; теги берутся из `format` и `topic`. `draft: true` исключает материал из сайта и сборки.
3. Для каждой статьи используйте отдельную папку `assets/posts/<slug>/`. Положите туда обложку (`cover.jpg` или `cover.png`) и укажите её в шапке, например: `cover: assets/posts/my-project/cover.png`. Если `cover` пустое, сборщик по умолчанию ищет `assets/posts/<slug>/cover.jpg`. При отсутствии файла обложка не отображается.
4. Чтобы вставить несколько изображений между частями статьи, положите файлы в ту же папку и добавьте каждое изображение отдельной строкой в нужном месте Markdown: `![Подпись к изображению](assets/posts/my-project/01-diagram.png)`. Оставляйте пустые строки вокруг маркера; порядок маркеров задаёт порядок изображений в статье.
5. Ниже шапки поддерживаются абзацы, `## заголовки`, списки `- пункт`, `**жирный текст**`, `` `код` ``, `[ссылка](https://example.com)` и Markdown-изображения.
6. Выполните `python3 build.py` и обновите страницу сайта.

Лента сама распределяет карточки по ширине. Значение `size` остаётся за редактором: `мини` — компактная карточка, `средняя` — материал обычного размера, `большая` или `статья` — крупная карточка; фактическая ширина подстраивается под соседние карточки и доступное пространство.

В подвале для сотрудничества указан адрес `cooperation@ai-business-spb.ru`. Telegram-ссылка находится только в блоках «Присоединяйтесь к сообществу».

Видимые теги карточки задаются полями `format` и `topic`; `size` влияет только на раскладку. `featured: true` выбирает материал для блока «Проекты изнутри». Черновик можно оставить в `content/posts/` с `draft: true` — его текст сохранится, но материал не попадёт в ленту и сборку.

## Имена и расположение изображений

Фотографии — JPG, логотипы — PNG (желательно с прозрачным фоном). Если файл отсутствует или не загружается, изображение/его слот автоматически скрывается.

| Использование | Путь |
| --- | --- |
| Логотипы бегущей строки: VIZARD, Mediascope, НейроДВС, Балтийский Берег, Yandex AI Studio, ИТ-Диалог, ГУАП | `assets/logos/vizard.png`, `mediascope.png`, `neurodvs.png`, `baltic-bereg.png`, `yandex-ai-studio.png`, `it-dialog.png`, `guap.png` |
| Обложка длинной статьи о проекте ChatBoost | `assets/posts/chatboost-grant/cover.png` |
| Фото в карточке хакатона (4 горизонтальных кадра) | `assets/hackathon/gallery-01.jpg` … `gallery-04.jpg` |
| Фото-мокапы страницы хакатона | `assets/hackathon/partner-case-review.jpg`, `assets/hackathon/mentor-briefing.jpg` |
| Фото кейсов | `assets/hackathon/cases/vizard.jpg`, `mediascope.jpg`, `neurodvs.jpg`, `baltic-bereg.jpg` |
| Обложка поста со slug `example-post` | `assets/posts/example-post/cover.jpg` (автоматически) |
| Фото внутри статьи | Храните в `assets/posts/<slug>/`, вставляйте в Markdown в нужном месте: `![Описание](assets/posts/<slug>/01-photo.jpg)`; можно несколько изображений |

Для кейсов укажите `logo: assets/logos/<slug>.png` и `cover: assets/hackathon/cases/<slug>.jpg` в Markdown-файле кейса. Пустые папки сохранены с помощью `.gitkeep`.
